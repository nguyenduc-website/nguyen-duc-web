📁 THƯ MỤC ẢNH / LOGO
======================

Đặt file logo của bạn vào thư mục này với tên: logo.png

Nếu không có file logo.png, website sẽ tự động dùng ảnh mặc định online.

Định dạng khuyến nghị:
- Kích thước: 400x400px (vuông)
- Định dạng: PNG (có nền trong suốt) hoặc JPG
- Dung lượng: < 500KB

Ngoài ra, bạn có thể upload logo trực tiếp từ Admin Dashboard
(Đăng nhập → Quản trị → Logo & Brand → Upload logo)
